# ACLS Code Leader v3.1 — Quiz 260

開發者：奇美加護醫學部專科護理師 洪苡瑾

## v2.9
- 新增 ACLS 題庫：260 practice items。
- 題庫結構：65 個 ACLS core concepts × 4 個情境/問法變體，避免只背固定句型。
- 分類：
  - High-quality CPR / Airway
  - Cardiac Arrest
  - Bradycardia
  - Tachycardia
  - Post-ROSC
- 練習模式：立即正解＋解析。
- 考試模式：20 / 50 / 100 題，結束後才顯示總分及錯題。
- 錯題重練。
- 抽題邏輯優先避免短時間重複同一 core concept。
- 題目依 2025 AHA ACLS/BLS 核心建議自行編寫，不重製 AHA 官方考題。

- ECG Lab 155 strips / 31 diagnoses / AV Block Focus
- Leader selected cases
- Practice / Exam / Pressure mode
- ECPR awareness prompt
- Mega Code research scoring / SPSS-ready export
- Auto Report / Code Clock experimental tool

## v3.0 — Mega Code 80
- Mega Code 45 → 80 cases；原 45 題全部保留，新增 35 題。
- 新增情境涵蓋：
  - Cardiac arrest：ischemic VF、severe asthma/obstructive PEA、drowning、anaphylaxis、septic shock、massive GI bleeding、post-op tamponade、hyperkalemia。
  - Bradycardia：inferior MI sinus brady、hyperkalemia brady、AF slow response、sinus pause、ventricular escape、post-procedure CHB、asymptomatic brady。
  - Tachycardia：stable AF RVR、sinus tachycardia due cause、atrial tachycardia、SVT vagal/adenosine conversion、stable flutter、irregular WCT、recurrent VT、torsades with pulse、accelerated junctional rhythm。
  - Advanced progression：hypoxia→brady→PEA、STEMI→VT→VF、hyperK WCT→PEA、AF→VT→VF、SVT→WCT→pVT、ROSC→PEA re-arrest、recurrent torsades、CCB toxicity、obstructive PEA→VF、CHB→VT→VF。
- Research scoring / SPSS export、Leader case selection、Practice / Exam / Pressure、Quiz 260、ECG Lab 155、AV Block Focus 均保留。
