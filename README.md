# ACLS Code Leader v2.9 — Quiz 260

開發者：奇美加護醫學部專科護理師 洪苡瑾

## v2.9
- 新增 ACLS 題庫：260 practice items。
- 題庫結構：65 個 ACLS core concepts × 4 個情境/問法變體，避免只背固定句型。
- 分類：
  - High-quality CPR / Airway
  - Cardiac Arrest
  - Bradycardia
  - Tachycardia
  - Post-ROSC
- 練習模式：立即正解＋解析。
- 考試模式：20 / 50 / 100 題，結束後才顯示總分及錯題。
- 錯題重練。
- 抽題邏輯優先避免短時間重複同一 core concept。
- 題目依 2025 AHA ACLS/BLS 核心建議自行編寫，不重製 AHA 官方考題。
